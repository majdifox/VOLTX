# VoltX Backend

Spring Boot backend API for the VoltX adrenaline-driven social platform.

## Tech Stack

- **Spring Boot 3.2.3** - Framework
- **Java 17** - Programming language
- **PostgreSQL** - Database
- **Spring Security** - Authentication & Authorization
- **JWT** - Token-based authentication
- **JPA/Hibernate** - ORM
- **Maven** - Build tool

## Getting Started

### Prerequisites

- Java 17+
- Maven 3.6+
- PostgreSQL 12+

### Running

```bash
./mvnw spring-boot:run
```
